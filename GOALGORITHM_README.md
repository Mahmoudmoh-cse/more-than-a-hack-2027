## Install

Python 3.10 or 3.11 is recommended. Validated here on Windows, Python 3.10.11. The implementation uses portable paths and has a Windows/Linux synthetic CI workflow.

Windows PowerShell:

```powershell
cd more-than-a-hack-2027
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-goalgorithm.txt
python -m pip check
$env:PYTHONUTF8 = "1"
```

Linux:

```bash
cd more-than-a-hack-2027
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-goalgorithm.txt
python -m pip check
export PYTHONUTF8=1
```

## Run on the authorized bundle locally

Place the participant-authorized tactical files in `./data/tactical/` (or set `MTAH_DATA_DIR`):

```text
data/tactical/BAR-ATH_tactical_atd.xml
data/tactical/BAR-ATH_tactical_atd.txt
data/tactical/BAR-ATH_tactical_smart_tagging.xml
```

**Single command to regenerate the exact final v2 submission (`Goalgorithm.csv`):**

```bash
python -X utf8 run_goalgorithm.py --data-dir ./data --config configs/v2.json --output Goalgorithm.csv
```

Verify the final submission file in your standalone local terminal:

```bash
python -X utf8 evaluation/validate_submission.py Goalgorithm.csv
```

To reproduce the preserved Phase 1 safety baseline (`v1`, backed up at `artifacts/local_backup/Goalgorithm_v1.csv`):

```bash
python -X utf8 run_goalgorithm.py --data-dir ./data --config configs/temporal.json --output artifacts/local_backup/Goalgorithm_v1_repro.csv
```

Do not paste validator counts or match-derived `.diagnostics.json` summaries into hosted AI services. Inference is deterministic (`run_goalgorithm.py` uses no randomness and makes no network calls).
